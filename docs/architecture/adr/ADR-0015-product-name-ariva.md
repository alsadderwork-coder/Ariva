# ADR-0015: Product and code name Ariva

- Status: Accepted
- Date: 2026-10-01
- Source: Product owner decision, 2026-10-01

## Context

Design documents D1 to D7 use the working name "Airport QMS". The repository, namespaces, topics and charts need a stable name before the first commit.

## Decision

The product and code name is Ariva. .NET projects and namespaces are `Ariva.*`; Kafka topics are `ariva.*`; the repository is `D:\DevOps\Ariva`. "Airport QMS" in D1 to D7 means Ariva.

## Consequences

- Design documents keep the working name; this repository uses Ariva throughout.
- Trademark and domain availability for "Ariva" in target markets: To confirm (not covered by the sources).

## Alternatives considered

- Keep "QMS" or "Airport QMS". Rejected: generic, not distinctive as a product name.
